# CIPHER

CIPHER is a Bayesian modeling framework for matrix factorization in biomedical data analysis.  
It is designed to estimate latent biological structure while providing probabilistic uncertainty quantification.

The project focuses on applications such as high-dimensional omics data, latent factor recovery, and related matrix-factorization problems.

## Features

- Bayesian matrix factorization
- Probabilistic estimation of latent factors
- Uncertainty quantification through posterior inference
- Support for multiple inference strategies
- Simulation utilities for model evaluation
- Tools for evaluating factor and network recovery


The broader objective is to develop statistically rigorous and computationally practical methods for analyzing complex biomedical datasets.

## Current Status

CIPHER is currently under active research and development.

Ongoing work includes:

- implementation of posterior inference methods

The codebase and documentation are still being developed and may change as the methodology evolves.
